# 🛡️ NexAdmin

A secure User Management System developed using PHP and MongoDB.

## Features

- User Authentication
- Admin Dashboard
- User Management (CRUD)
- User Search
- Profile Management
- Change Password
- Role-Based Access
- Dark/Light Theme
- Responsive Design
- Chart.js Dashboard

## Technologies Used

- PHP
- MongoDB
- Bootstrap 5
- JavaScript
- Chart.js
- HTML5
- CSS3

## Installation

1. Clone the repository.
2. Run:

composer install

3. Start Apache and MongoDB.
4. Open:

http://localhost/NexAdmin/login.php
