# 🛡️ NexAdmin

A secure User Management System developed using PHP and MongoDB.

## Features

- User Authentication
- Admin Dashboard
- User Management (CRUD)
- User Search
- Profile Management
- Change Password
- Role-Based Access
- Dark/Light Theme
- Responsive Design
- Chart.js Dashboard

## Technologies Used

- PHP
- MongoDB
- Bootstrap 5
- JavaScript
- Chart.js
- HTML5
- CSS3

## Installation

1. Clone the repository

git clone https://github.com/jenifer04p-beep/NexAdmin.git

2. Open the project

cd NexAdmin

3. Install dependencies

composer install

4. Start Apache using XAMPP.

5. Ensure MongoDB Server is running.

6. Create the admin account

http://localhost/NexAdmin/create_admin.php

7. Run

http://localhost/NexAdmin/login.php
